# ChinesePlus browser extension

Popup dictionary for reading chinese on any site: hover a chinese character (tap it on a phone)
to see the longest dictionary word starting there, the shorter ones under it, their pinyin and
meanings, and a button that opens the word on chineseplus.club (examples, stroke order,
adding it to your words). Works offline: the dictionary ships inside the extension.

## How it works

- `dict/`: generated by `server/scripts/export-extension-dictionary.js` from
  `dictionarytranslations` + `dictionaries`. Only words of 1-4 chinese characters (so chengyu are
  included), only pinyin and meanings (`senses`), no examples. Rare words are left out: a word of
  2+ characters is exported only if nodejieba's word list has it with frequency >= 5 (`--min-freq`)
  or as an idiom, or it is an HSK word; all single characters are kept. That is ~130k of the
  1.46M words: 22.6 MB unpacked, 8 MB zip (`--min-freq=20`: 18.7 MB / 6.6 MB; `--all-words`:
  158 MB / 53 MB). Words are split into 512 bucket
  files by their first character, so a hover reads one small file. Traditional forms point to
  the simplified word. File format: see the script's header.
- `background.js`: answers `lookup` messages from the content script from `dict/`, keeps
  recently used buckets in memory.
- `content.js` + `content.css`: finds the character under the pointer, collects up to 4
  characters, highlights the matched word and shows the popup (closed shadow DOM, built with DOM
  APIs only). Senses are laid out like the site's tooltips
  (`qwik/src/misc/helpers/translation/senses-to-html.ts`).
- `popup.html`: toolbar button: on / off switch. Desktop shortcut `Alt+Shift+Y` (`Option+Shift+Y` on macOS); on phones, the switch in the extension menu.
- The content script does not run on chineseplus.club, which has its own tooltips.

## Build

```sh
cd server
node scripts/export-extension-dictionary.js   # prints the number of words and the size
../extension/package.sh                       # -> extension/dist/chineseplus-<version>.zip
```

The script reads the database from `server/config/.env.prod` (or `.env.dev` with
`NODE_ENV=development`), like the other scripts. `dict/` and `dist/` are not committed.
Bump `version` in `manifest.json` for every store upload.

## Try it locally

- Chrome / Edge / Yandex / Opera: `chrome://extensions` → Developer mode → Load unpacked →
  select `extension/`.
- Firefox: `about:debugging#/runtime/this-firefox` → Load Temporary Add-on → select
  `extension/manifest.json`.

## Publishing

| Browser | Where | Notes |
| --- | --- | --- |
| Chrome, Yandex, Opera, Brave | Chrome Web Store | the zip as is; one-time $5 developer fee |
| Edge | Microsoft Edge Add-ons | the same zip |
| Firefox desktop + Android | addons.mozilla.org | the same zip; tick Android compatibility. ID: `dictionary@chineseplus.club` |
| Safari macOS / iOS / iPadOS | App Store | `xcrun safari-web-extension-converter extension/` makes an Xcode project; needs an Apple Developer account |

Mobile: Firefox for Android and Safari on iOS / iPadOS run extensions; Chrome for Android does
not. Some Chromium-based Android browsers install Chrome Web Store extensions too.
