# ChinesePlus browser extension

Popup dictionary for reading chinese on any site: hover a chinese character (tap it on a phone)
to see the longest dictionary word starting there, the shorter ones under it, their pinyin and
meanings, the word's HSK 3.0 level, a button that opens the word on chineseplus.club (examples,
stroke order, adding it to your words), and buttons to hear the word and to copy it (alone or
with its meanings). Works offline: the dictionary ships inside the extension.

## How it works

- `dict/`: generated by `server/scripts/export-extension-dictionary.js` from
  `dictionarytranslations` + `dictionaries`. Only words of 1-4 chinese characters (so chengyu are
  included), only pinyin and meanings (`senses`), no examples; plus the lowest HSK 3.0 level of
  the words in `hskword2025` (bucket field `h`; a dictionary exported before it shows no badges). Rare words are left out: a word of
  2+ characters is exported only if nodejieba's word list has it with frequency >= 5 (`--min-freq`)
  or as an idiom, or it is an HSK word; all single characters are kept. That is ~130k of the
  1.46M words: 22.6 MB unpacked, 8 MB zip (`--min-freq=20`: 18.7 MB / 6.6 MB; `--all-words`:
  158 MB / 53 MB). Words are split into 512 bucket
  files by their first character, so a hover reads one small file. Traditional forms point to
  the simplified word. File format: see the script's header.
- `background.js`: answers `lookup` messages from the content script from `dict/`, keeps
  recently used buckets in memory.
- `lib.js`: shared by `content.js` and the extension's pages: rendering of entries (senses, pinyin
  tone colors, HSK, icons), speech, copy. Loaded first (manifest, `<script>` tags).
- `search.js` + `results.css`: offline search on the extension's pages: Chinese text typed or
  pasted is split into words (the longest dictionary word from each position) and looked up
  through `background.js`. Pinyin and Russian go to the site's dictionary: the extension's
  dictionary is indexed by the first character only. A single word searched counts as looked up.
  Used by the menu (`popup.html`, search box at the top) and `dictionary.html` (the same on a
  page of its own, opened in a tab from the menu; the query stays in `#q=`).
- `content.js` + `content.css`: finds the character under the pointer, collects up to 4
  characters, highlights the matched word and shows the popup (closed shadow DOM, built with DOM
  APIs only). Senses are laid out like the site's tooltips
  (`qwik/src/misc/helpers/translation/senses-to-html.ts`). Audio is the browser's own speech
  synthesis (`speechSynthesis`, a mandarin voice when there is one: nothing to download; the
  button is hidden when the browser has no chinese voice). Pinyin tone colors split the
  dictionary's unspaced pinyin into syllables with a regex (`SYLLABLE_RE`).
  "+" (add to my words) opens `/dictionary/<word>?add=1` on the site: the extension has no login.
  The site asks before adding (a link from any page could carry `add=1`); without a login the
  page's `onGet` sends the user to `/login?next=…` first, and login / registration / Google
  OAuth come back there (`qwik/src/misc/helpers/login-next.ts`).
- Bigger Chinese text (setting `textScale`, 100–200%): `content.js` multiplies the font size
  of every element with Chinese text of its own (inline `!important`, the original kept and
  restored), not the page zoom, so lines wrap to the screen; new content via a MutationObserver.
- `popup.html`: toolbar button: on / off switch, text size, theme, "words inside the word", pinyin tone
  colors, "only while Shift is held" (mouse: moving the pointer opens no new words, pressing
  Shift looks up the word under it).
- Looked-up words: `content.js` reports a word once per page when its popup stayed on it 1 s
  (a tap or Shift: at once); `background.js` keeps the last 300 in `storage.local` `history`
  (`[word, times, last ms]`, nothing from private windows, setting `saveHistory`). The menu
  (`popup.html`) shows them and opens `chineseplus.club/dictionary/import#w=<word:times,…>`:
  the site's page (`qwik/src/routes/dictionary/import/`) reads the fragment in the browser,
  keeps it in sessionStorage through a login, and adds the checked words on the FE server. Desktop shortcut `Alt+Shift+Y` (`Option+Shift+Y` on macOS); on phones, the switch in the extension menu.
- The content script does not run on chineseplus.club, which has its own tooltips.

## Build

```sh
cd server
node scripts/export-extension-dictionary.js   # prints the number of words and the size
../extension/package.sh                       # -> extension/dist/chineseplus-<version>.zip
```

The script reads the database from `server/config/.env.prod` (or `.env.dev` with
`NODE_ENV=development`), like the other scripts. `dict/` and `dist/` are not committed.
Bump `version` in `manifest.json` for every store upload.

## Try it locally

- Chrome / Edge / Yandex / Opera: `chrome://extensions` → Developer mode → Load unpacked →
  select `extension/`.
- Firefox: `about:debugging#/runtime/this-firefox` → Load Temporary Add-on → select
  `extension/manifest.json`.

## Publishing

| Browser | Where | Notes |
| --- | --- | --- |
| Chrome, Yandex, Opera, Brave | Chrome Web Store | the zip as is; one-time $5 developer fee |
| Edge | Microsoft Edge Add-ons | the same zip |
| Firefox desktop + Android | addons.mozilla.org | the same zip; tick Android compatibility. ID: `dictionary@chineseplus.club` |
| Safari macOS / iOS / iPadOS | App Store | `xcrun safari-web-extension-converter extension/` makes an Xcode project; needs an Apple Developer account |

Mobile: Firefox for Android and Safari on iOS / iPadOS run extensions; Chrome for Android does
not. Some Chromium-based Android browsers install Chrome Web Store extensions too.
